# Proposta Comercial — Cuscuzeria Gourmet

## 1. Apresentação

A Cuscuzeria Gourmet é um projeto de restaurante e cardápio digital com foco em identidade visual nordestina, funcionalidade para pedidos e valorização da experiência gastronômica.

A proposta abaixo contempla a criação e entrega de uma landing page moderna, responsiva e preparada para apresentação comercial, com foco em conversão, clareza de informação e integração com canais de atendimento e pedidos.

---

## 2. Escopo do projeto

### Desenvolvimento web
- Landing page institucional
- Layout responsivo para desktop e mobile
- Seção de destaque para pedidos via iFood e WhatsApp
- Estrutura de cardápio com visual premium
- Carrinho e fluxo de pedido
- Navegação clara e intuitiva
- Estética refinada com identidade nordestina

### Funcionalidades inclusas
- Página inicial com apresentação da marca
- Cardápio digital
- Visualização de produtos por categoria
- Carrinho de compras
- Botões de ação para WhatsApp e iFood
- Links para Instagram e contato
- Estrutura pronta para publicação em domínio

### Entregáveis
- Código-fonte completo do projeto
- Site responsivo funcionando em desktop e mobile
- Ajustes visuais finais
- Build de produção pronto para deploy
- Preparação para publicação em domínio

## 4. O que está incluso

- Criação do layout visual
- Desenvolvimento do site em React + Vite
- Ajustes de UX/UI
- Responsividade mobile
- Botões de WhatsApp e iFood
- Estrutura de cardápio e produtos
- Carrinho de compras
- Organização visual de marca e identidade
- Build de produção
- Suporte básico para publicação

---

## 5. O que não está incluso

- Fotos profissionais externas de produto ou ambiente
- Produção de vídeo institucional
- Criação de identidade visual completa desde zero (se houver necessidade, pode ser cotada separadamente)
- Gestão de tráfego pago e marketing digital
- Conteúdo editorial completo e textos de marketing premium
- Integração avançada com sistema de pedidos externo, ERP ou gestão completa
